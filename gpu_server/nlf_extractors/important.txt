Use this folder to create an extractor python file which uses the nlf model to extract frames from videos. Files can be created later from our current functional notebooks:

1. Extract frames
2. Apply nlf
3. Turn to jsonl

It is made in one file, and it can be used by :
"
from process_video import process_video

output_path, fps = process_video("/path/to/video.mp4")"

 And it will give the fps to pass to the pipeline, as well as the path of the jsonl.
